# OPS Board — дашборд для группы VK

Мини-дашборд: статус игровых серверов (онлайн + пинг) и события на одном экране.

## Как открыть с реальным мониторингом

```bash
py monitor.py
```

Откройте http://127.0.0.1:5173/

Серверы настраиваются в `servers.json`. Статус обновляется каждые 3 секунды через `/api/status`.

> Браузер сам не может пинговать игровые порты — для этого нужен `monitor.py`.

## Что дальше для VK

1. Создать мини-приложение в [VK для разработчиков](https://dev.vk.com/)
2. Залить эти файлы на хостинг (HTTPS обязателен)
3. Привязать приложение к сообществу
4. Подключить реальный мониторинг серверов (API / query) вместо демо в `app.js`
5. Добавить админку для событий или тянуть их из вашей БД

## Структура

- `index.html` — разметка дашборда
- `styles.css` — оформление
- `app.js` — данные и «живое» обновление
