# OPS Board — дашборд для группы VK

Сайт: https://dramitelego-netizen.github.io/ops-board/

## Запуск на компьютере

Двойной клик по файлу:

- `start.bat` — открывает дашборд и включает живой пинг
- `update-status.bat` — один раз обновляет `status.json`

## Что где лежит

| Файл | Назначение |
|------|------------|
| `servers.json` | список серверов для мониторинга |
| `events.json` | события (можно дополнять текстом из VK) |
| `status.json` | последний пинг (обновляет GitHub Actions) |
| `monitor.py` | локальный живой мониторинг |

## События из VK

Сейчас события берутся из `events.json`.  
Поле `text` — для подробностей (описание из поста VK и т.п.).

Позже можно добавить автозагрузку постов/событий из сообщества VK в этот же файл.

## GitHub Pages

Пинг на сайте обновляется через GitHub Action примерно каждые 5 минут.
