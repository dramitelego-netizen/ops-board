# Виджет на главной группы VK

Чтобы статус серверов был **сразу виден** на странице сообщества (без входа в приложение).

## Важно

Нужен тип приложения **«Плагин для сообществ»** (не обычное мини-приложение).  
Если сейчас другое — создайте плагин на [dev.vk.com](https://dev.vk.com/) и укажите URL:

`https://dramitelego-netizen.github.io/ops-board/`

## Установка (один раз)

1. Добавьте плагин в сообщество (Управление → Приложения) **или** откройте его из группы.
2. Откройте плагин **из сообщества** под админом.
3. Внизу появятся кнопки:
   1. **Добавить в сообщество**
   2. **Установить виджет** — подтвердите в окне VK
   3. **Получить токен обновления** — токен скопируется
4. На GitHub: репозиторий `ops-board` → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
   - Name: `VK_COMMUNITY_TOKEN`
   - Value: вставьте токен

## Как обновляется

### Режим 30 секунд (нужен постоянно включённый ПК/сервер)

1. Получите токен кнопкой в приложении VK
2. Создайте файл `.env` из `.env.example`
3. Вставьте: `VK_COMMUNITY_TOKEN=ваш_токен`
4. Запустите `start-30s.bat` и **не закрывайте** окно

Пока скрипт работает:
- пинг серверов каждые 30 сек
- виджет в группе обновляется каждые 30 сек (лимит VK)

### Если ПК выключен

GitHub Action обновляет примерно раз в 1 минуту (как запасной режим).

На главной группы будет блок вроде:

```
Серверы · 6/6 online
Белый: Online · 24 ms
Синий: Online · 31 ms
...
```
