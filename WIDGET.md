# Виджет под шапкой группы

На главной сообщества сразу видно список серверов (Online / пинг).

## 1. Создайте плагин

1. [dev.vk.com](https://dev.vk.com/) → **Создать** → тип **Плагин для сообществ**
2. URL: `https://dramitelego-netizen.github.io/ops-board/`
3. Включите **Запуск приложения из сообщества**
4. Состояние: **Включено**

## 2. Добавьте в группу и поставьте виджет

1. Сообщество → **Управление** → **Приложения** → добавить плагин  
   **или** откройте плагин и нажмите кнопку **1. Добавить плагин в сообщество**
2. Откройте плагин **из сообщества** (под админом)
3. Нажмите **2. Установить виджет**
4. В окне VK подтвердите установку

После этого на главной группы появится компактная таблица:

```
OPS · 6/6 online
Серверы                    | События
Белый · On · 24            | Скоро — Пока на проверке
Синий · On · 31            |
...
```

## 3. Автообновление каждые 30 секунд

1. В приложении: **3. Токен для автообновления**
2. В папке проекта создайте `.env`:

```env
VK_COMMUNITY_TOKEN=ваш_токен
VK_APP_ID=ваш_id_приложения
```

3. Запустите `start-30s.bat` и не закрывайте окно

Пока скрипт работает — виджет обновляется roughly каждые 30 секунд.
